# Climate analysis

## Data

[Geosphere Messdaten](https://data.hub.geosphere.at/dataset/)

## Example data Innsbruck

Parameters (7 von 420)

- `absf_mittel` ...Absolute Feuchte Mittelwert g/m³
- `p` ...Luftdruck Mittelwert hPa
- `tl_i_mittel` ...Lufttemperatur 2m Mittelwert Termin I °C
- `tlmin` ...Lufttemperatur 2m Minimalwert °C
- `tlmax` ...Lufttemperatur 2m Maximalwert °C
- `so_h` ...Sonnenscheindauer h
- `tage_schreg` ...Tage mit Schneefall und Regen d
